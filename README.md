# AI Study Planner

## 📌 Project Overview
AI Study Planner is an intelligent system that generates personalized study schedules based on user goals, subjects, and available time. It helps students manage time efficiently and improve productivity using AI-driven planning.

---
## 🚀 Features
- Personalized study schedule generation
- Goal-based planning (exams, deadlines)
- Smart time allocation based on priority
- Adaptive recommendations
- Simple and user-friendly interface

---
## 🧠 Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Jupyter Notebook

---
## ⚙️ How It Works
1. User inputs subjects, goals, and available time
2. System analyzes priorities and difficulty
3. AI generates an optimized study plan
4. Tasks are distributed across time slots
5. User follows the schedule
